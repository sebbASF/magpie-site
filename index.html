Apache Magpie handles the repetitive parts of running an open-source project — triaging issues and PRs, mentoring contributors, drafting fixes, managing security reports — so maintainers can spend their time on design, relationships, and the work that needs a human. The agent proposes; the human decides.

Security First
Built with security at every layerEvery interaction is auditable, every decision is transparent, and every action respects the principle of least privilege.
Sandboxed by DefaultFilesystem, network, and tool-permission rules enforced at the harness layer. Sandbox bypasses warn loudly, never silently.
Privacy-Aware RoutingPrivate content flows only to LLMs your PMC has explicitly approved, with a recorded data-residency contract.
PII RedactionThird-party PII is redacted to stable identifiers before any content reaches an LLM context.
Full Audit LogEvery agent-authored action — comment, label, draft, PR — is logged and reversible where possible.
Pinned & Signed DepsEvery system tool is pinned and aged through a cooldown window. Version bumps are reviewed PRs, not silent updates.
Human-in-the-LoopEvery outward action needs explicit maintainer confirmation. External content is treated as data, never instructions.
